Cómo se clonó

HTML+CSS plano inspirado en director-ia-pi.vercel.app. Paleta extraída del CSS compilado de Next.js del sitio original: navy #0b1f5c, amarillo BanCoppu #ffcd00, fuentes Bricolage Grotesque + Figtree, easing cinematográfico cubic-bezier(.22, 1, .36, 1), film grain SVG inline. Las animaciones (entrada escalonada, underline scaleX, blink REC, confeti shimmer, typewriter del Director IA) están implementadas con CSS transitions + vanilla JS.
